# 보안 요구사항 (Security Requirements)

## 1. 인증 및 접근 제어
- **사용자 인증**: Firebase Authentication을 통한 고유 계정 관리.
- **방 접근 제한**: 비밀번호 설정을 통한 비공개 세션 생성 기능 제공.

## 2. 네트워크 보안
- **패킷 암호화**: Photon 내부 프로토콜을 이용한 기본 통신 암호화 적용.
- **데이터 변조 방지**: 중요 게임 로직(아이템 획득, 보스 처치)은 호스트 클라이언트를 권위적 서버(Authoritative)로 사용하여 검증.

## 3. 데이터 보호
- **개인정보**: 사용자의 이메일 외에 민감한 개인정보는 수집하지 않음.
- **세이브 변조 방지**: JSON 저장 데이터의 체크섬(Checksum) 검증을 통해 로컬 데이터 무단 수정 감지.
