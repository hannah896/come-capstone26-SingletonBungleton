# 인터페이스 요구사항 (Interface Requirements)

## 1. 사용자 인터페이스 (UI)
- **HUD**: 화면 상단에 시간/날짜/달 위상 표시, 우측 하단에 생존 스탯(HP, 허기, 정신력) 원형 UI 배치.
- **인벤토리**: 15칸의 기본 슬롯 및 3칸의 장착 슬롯(머리, 가슴, 손) 제공. 드래그 앤 드롭 지원.
- **제작 메뉴**: 카테고리별 탭 메뉴와 재료 보유 현황 확인 인터페이스.

## 2. 하드웨어 인터페이스
- **입력 장치**: 키보드(WASD, F, Tab, E, M) 및 마우스(좌클릭: 공격/채집, 우클릭: 상호작용).
- **해상도**: 16:9 비율을 기본으로 하며, 다양한 해상도에 대응하는 UI Canvas 스케일러 적용.

## 3. 외부 API 및 통신 인터페이스
- **Photon API**: 멀티플레이어 세션 관리 및 실시간 RPC(Remote Procedure Call) 통신.
- **Firebase API**: JSON 기반의 사용자 프로필 및 월드 저장 데이터 읽기/쓰기.
- **UGS API**: 구글 시트 기반의 아이템 밸런스 데이터 파싱 및 연동.
