# 시스템 장비 구성요구사항 (v1.1)

본 문서는 기획서(SingletonBungleton)에 명시된 **로그라이트 생존 멀티 플레이 게임**의 개발 및 실행을 위한 최적화된 요구사항을 정의합니다.

## 1. 개발 환경 (Development Environment)

기획서의 '시드 기반 랜덤 맵 생성' 및 'HFSM 기반 복합 AI' 처리를 위해 CPU와 RAM의 성능이 중요합니다.

### 1.1. 하드웨어 요구사항
| 구분 | 최소 사양 | 권장 사양 | 비고 |
| :--- | :--- | :--- | :--- |
| **CPU** | Intel Core i5 / AMD Ryzen 5 | Intel Core i7 / AMD Ryzen 7 | 맵 생성 및 AI 연산 최적화 |
| **RAM** | 16 GB | 32 GB | 멀티플레이 로컬 테스트(2~4 클라이언트) 고려 |
| **GPU** | NVIDIA GTX 1660 / AMD RX 5500 XT | NVIDIA RTX 3060 이상 | Unity 6 URP 및 실시간 라이팅 처리 |
| **Storage** | 50GB SSD | 100GB NVMe SSD | 에셋 라이브러리 및 빌드 속도 향상 |
| **Network** | 100Mbps 광랜 | 1Gbps 초고속 인터넷 | P2P 멀티플레이 개발 및 동기화 테스트 |

### 1.2. 개발 소프트웨어 구성
- **Engine**: Unity 6 (6000.0.60f1) - **기획서 지정 버전**
- **IDE**: Visual Studio 2022 (C# 스크립팅)
- **Database/Backend**: Firebase (JsonUtility를 통한 JSON 데이터 관리 연동)
- **Multiplayer**: Photon Bolt 또는 Fusion (1~4인 P2P 서버 지원)
- **Version Control**: Git (LFS 활용 필수)

---

## 2. 서버 및 네트워크 구성 (Infrastructure)

기획서 2페이지의 '멀티 플레이 시스템' 요구사항을 반영합니다.

- **P2P 아키텍처**: 별도의 데디케이트 서버 없이 플레이어 중 한 명을 호스트(Host)로 설정하는 방식.
- **Relay Server**: 방화벽 및 NAT 환경에서의 원활한 연결을 위해 Photon Relay 사용.
- **Data Persistence**: 플레이어 능력치, 인벤토리 상태, 건축물 배치는 Firebase/JSON 기반으로 저장.
- **API 연동**: UGS(Uni-Google-Sheets)를 통한 게임 밸런스(허기 감소율, 자원 재생성 주기 등) 실시간 관리.

---

기획서의 1인칭 백뷰 및 실시간 전투 시스템을 고려한 사양입니다.

### 3.1. PC 플랫폼 (Windows/macOS)
| 구분 | 최소 사양 | 권장 사양 |
| :--- | :--- | :--- |
| **OS** | Windows 10 (64-bit) | Windows 10/11 (64-bit) |
| **CPU** | Intel Core i3 10세대 / Ryzen 3 3000 | Intel Core i5 12세대 / Ryzen 5 5000 |
| **RAM** | 8 GB | 16 GB |
| **GPU** | GTX 1050 (VRAM 2GB) | GTX 1660 Ti / RTX 3050 |
| **DirectX** | 버전 11 이상 | 버전 12 |

### 3.2. 네트워크 안정성
- **최소 대역폭**: 10Mbps 이상의 업로드/다운로드 속도 (4인 플레이 시 데이터 동기화 목적)
- **Ping**: 호스트 기준 50ms 미만 권장

---

## 4. 특이 사항 (Project Specifics)
- **1인칭 시점(First Person)**: 실시간 카메라 연산 및 렌더링 최적화가 필요합니다.
- **시드 기반 맵 생성**: 첫 로딩 시 CPU 부하가 높을 수 있으므로 비동기(Async) 로딩 처리가 필수적입니다.
- **상태 머신(HFSM)**: 많은 수의 몬스터와 동물 AI가 동시에 동작하므로, 성능 저하 방지를 위해 오브젝트 풀링(Object Pooling) 기술이 적용된 하드웨어를 전제로 합니다.
- **멀티 플레이 동기화**: P2P 방식 특성상 호스트의 PC 성능이 전체 게임 경험에 큰 영향을 미칩니다.
