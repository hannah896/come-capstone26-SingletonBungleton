# 데이터 요구사항 (Data Requirements)

## 1. 데이터 저장 구조
- **세이브 데이터**: 플레이어 위치, 인벤토리, 연구 해금 상태, 설치된 구조물 정보를 JSON 형식으로 저장.
- **월드 데이터**: 시드 번호, 자원 고갈 상태, 현재 시간 및 달 위상 데이터 보존.

## 2. 데이터베이스 구성
- **아이템 테이블**: 아이템 ID, 이름, 타입(소모품/도구/재료), 내구도, 스택 수량 등을 관리.
- **몬스터/보스 데이터**: 체력, 공격력, 이동 속도, 드랍 테이블 정보.
- **레시피 데이터**: 제작에 필요한 재료 목록 및 요구 연구 시설 단계.

## 3. 보안 및 무결성
- **로컬 캐싱**: 오프라인 플레이 시 로컬에 임시 저장 후 온라인 연결 시 Firebase와 동기화.
- **데이터 검증**: 클라이언트에서 전송된 제작/공격 데이터를 서버(호스트)에서 재검증하여 변조 방지.
