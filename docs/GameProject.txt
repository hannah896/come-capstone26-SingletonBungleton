2. 핵심 시스템

  ┌─────────────────────────────────────────────────┐
  │ 2.1 생존 관리 시스템                              │
  │ 구현 파일: PlayerStatData.cs / PlayerStatus.cs   │
  └─────────────────────────────────────────────────┘

  2.1.1 배고픔 (Hunger)
    수치
      최대값   : HungerDrain × DayDurationMinutes(12분) × 2
      감소량   : HungerDrain / 60f × deltaTime  (분당 감소)
    회복      : 음식 섭취
    디버프    : 배고픔 = 0 → 체력 HungerHPDecreaseRate × deltaTime 감소
    루프 의도  : 탐험 → 식량 수급 → 생존

  2.1.2 Ego (Ego)
    수치
      감소량   : EgoDecreaseRate × deltaTime  (초당 감소)
    회복      : 수면 / 안전지대 / 음식 / NPC 상호작용
    디버프
      - 방어력 감소
      - 공격력 감소
      - 경직 증가
      - 졸음 상태
      - 랜덤 아이템 소실

  2.1.3 체력 (HP)
    회복      : 아이템 / 수면
    디버프    : HP = 0 → 사망 (Dead 상태 전환)

  2.1.4 체온 (Temperature)
    상태      : 정상 / 추위 / 더위
    디버프
      - 추위(< MaxColdTemperature): ColdHPDecreaseRate × deltaTime 체력 감소
      - 더위(> MaxHotTemperature): HotHPDecreaseRate × deltaTime 체력 감소
      - 이동속도 감소
    조절
      - 상승: 불, 의복
      - 하강: 그늘, 냉각

  2.1.5 습도 (Wetness)
    최대값    : MaxWetness
    효과
      - 체온 감소 가속 (WetnessTemperatureDecreaseRate)
      - Ego 감소
      - 음식 부패 증가

6. Unity 아키텍처 참고

  매니저 구조 (Main.cs 중앙 허브)
    PrimaryManager  : ResourceManager, DataManager, UIManager, JSAMManager
    CoreManager     : PoolManager, ScreenManager, LoopManager, InputManager, NetworkManager, TimeManager
    ContentManager  : GameManager, SceneManagerEx

  주요 패턴
    - 커스텀 루프    : Main.Loop.OnGameUpdate / OnUpdate (Unity Update() 직접 사용 안 함)
    - 비동기 처리    : UniTask (async UniTask)
    - 에셋 로딩     : Addressables (ResourceManager 래퍼)
    - 네트워킹      : Photon Fusion (P2P)

  구현 예정 스크립트
    - WorldManager
    - TimeSystem (TimeManager 확장)
    - MoonSystem
    - BossSpawnSystem
    - MonsterAI (NavMesh 기반, 시간대별 행동 변화)
