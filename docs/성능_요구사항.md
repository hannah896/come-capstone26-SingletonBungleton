# 성능 요구사항 (Performance Requirements)

## 1. 그래픽 및 프레임워크
- **프레임 속도(FPS)**: 권장 사양 기준 FHD 해상도에서 안정적인 60 FPS 유지.
- **렌더링**: URP(Universal Render Pipeline)를 활용한 드로우 콜(Draw Call) 최적화 및 SRP Batcher 활성화.

## 2. 로딩 및 반응성
- **맵 생성 시간**: 새로운 월드 생성 시 10초 이내에 지형 및 오브젝트 배치 완료.
- **입력 지연**: 사용자 입력(공격, 이동)에 대한 반응 지연 시간 50ms 미만 유지.

## 3. 멀티플레이어 성능
- **네트워크 지연(Latency)**: P2P 환경에서 호스트와 클라이언트 간 핑(Ping) 100ms 미만 권장.
- **동기화 빈도**: 주요 상태값(위치, 체력)은 초당 최소 20회 이상 패킷 갱신.

## 4. 자원 관리
- **메모리 최적화**: 오브젝트 풀링(Object Pooling)을 통한 빈번한 인스턴스 생성/파괴 방지.
- **에셋 로딩**: Addressables 시스템을 활용하여 필요 시점에만 메모리에 로드.
