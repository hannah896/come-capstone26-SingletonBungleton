# 기획: 보스 포털(월문) 개방 조건 설계

> 작성일: 2026-10-18
> 대상: 최종 보스로 들어가는 포털의 **설치 · 개방 · 입장 · 클리어/실패** 규칙
> 근거: `기획_상위작업대_레시피.md`(월문 초안), `프로젝트_개요.md`(만월 보스, 거점 보스 레이드), 현재 구현 상태
> ※ 수치(재료 수량, 시간, 인원 규칙)는 **제안값**이다. 팀 결정 후 확정한다.

---

## 1. 한 줄 요약

> **세 마리 중간 보스를 모두 잡아 얻은 재료로 포털을 짓고, 보름달이 뜬 날 파티원이 모이면 열린다.**
> 안에서 최종 보스를 잡으면 엔딩, 전멸하면 거점으로 돌아오고 다음 보름에 재도전한다.

```
[준비]  연성대 제작 → 마력 무기 제작 → 중간 보스 3종 처치(재료 확보)
   ▼
[건설]  월문 제작·설치  (닫힌 상태)
   ▼
[개방]  보름달 + 파티원 집결 → 열림 (제한 시간)
   ▼
[입장]  범위 내 전원 동시 이동 → 보스 아레나
   ▼
[전투]  최종 보스 ──처치──▶ 엔딩
                  └─전멸──▶ 거점 귀환, 포털 닫힘, 다음 보름 재도전
```

## 2. 현재 게임과 맞물리는 사실

| 항목 | 현재 상태 | 설계에 주는 영향 |
|:--|:--|:--|
| 달 주기 | `WorldClock` 8일 주기(`MoonCycleDays=8`), 보름 = 위상 4 | 보름은 **5일차, 13일차, 21일차 …** (`(일차-1) % 8 == 4`) |
| 하루 길이 | 1일 = 1440초(현실 24분), 배속 최대 120배 | 보름 간격 = 현실 약 **3시간 12분**. 첫 보름은 현실 약 1시간 36분 후 |
| 만월 보스 | `BossSpawnRule`로 만월마다 8종 중 1종 순환 스폰 | 포털 재료를 "만월 보스 전리품"으로 요구하면 자연스럽게 게이트가 된다 |
| 플레이 인원 | 1~4인, 호스트 권위 멀티 | 입장/개방 판정은 **호스트가 확정**하고 클라이언트에 알린다 |
| 사망 규칙 | 소지품 전량 드롭 후 부활 | 보스 아레나 안에서는 **드롭 없음**으로 예외 필요 (4.3절) |
| 이동 | `Player.Teleport()` / `PlayerMotor.Teleport()` 있음 | 포털 이동에 그대로 쓴다 |
| 게임 상태 | `GameState`에 엔딩 없음 (`Failed`만 있음) | `Ending` 상태와 엔딩 화면을 새로 만들어야 한다 |
| 제작 | 연성대 + 마력 무기 6종 구현 완료 | 포털은 연성대에서 만드는 "다음 단계" 제작물로 얹는다 |

## 3. 포털 조건 (3단 게이트)

### 3.1 ① 건설 조건 — "포털을 지을 수 있는가"

**연성대 근처에서 월문 레시피를 제작**한다. 재료는 세 보스의 전리품을 **각 1종 이상** 요구해서, "세 마리를 다 잡아야 지을 수 있다"가 되게 한다.

| 재료 | 얻는 곳 | 수량(제안) |
|:--|:--|:--|
| 검은 악마 뿔 | 임프 데빌 | 3 |
| 진한 수액 + 초록 마력석 | 트리가드 | 각 2 |
| 악마 심장석 + 몬스터 꼬리 | 외눈 박쥐 메이지 | 각 2 |
| 마력 가루 | 박쥐/임프 | 6 |
| 철 / 금 / 판자 | 일반 자원 | 10 / 5 / 12 |

- 보스는 만월마다 1종씩만 나오므로, 재료를 모으는 데 **최소 만월 3번(= 현실 약 9시간)** 이 걸린다. 한 세션에 끝내려면 수량을 줄이거나 보스 스폰을 늘려야 한다 → **4절의 결정 사항 1**.
- 연성대 팝업의 "마력 무기" 탭 옆에 **"의식" 탭**을 추가해 거기서 만든다 (`RecipeCategory.Ritual` 신설).

### 3.2 ② 개방 조건 — "포털이 열리는가"

**모두 만족해야 열린다.**

| 조건 | 내용 | 비고 |
|:--|:--|:--|
| 시간 | `WorldClock.CurrentMoonPhase == Full` | **보름 하루 전체**(제안) 또는 보름 밤만(대안) |
| 집결 | 포털 반경 **6m** 안에 파티원이 모임 | 4절의 결정 사항 2 |
| 준비 점검 (경고만) | 마력 무기를 하나도 안 들고 있으면 경고 팝업 | 강제하지 않는다(클리어 가능성 보존) |

- 닫혀 있는 포털에 가까이 가면 **"다음 보름까지 N일"** 을 보여준다. 안 보이면 시스템이 없는 것과 같다.
- 한 번 열리면 **인게임 12시간(현실 12분)** 동안 유지하고, 다음 날 새벽에 닫힌다.

### 3.3 ③ 입장 조건 — "들어갈 수 있는가"

1. 열린 포털에서 누구든 E키 → 반경 안 **생존자 전원에게 입장 확인 팝업**.
2. 전원이 수락하면 5초 카운트다운 후 **동시에 이동**.
3. 한 명이라도 거절하면 취소. (방장 강제 시작은 대안)
4. 이미 입장한 뒤에는 **추가 입장 불가**(중도 참여 없음).

## 4. 결정이 필요한 것

| # | 질문 | 제안 | 대안 |
|:--|:--|:--|:--|
| 1 | 재료 수집 부담 | 위 표 수량 | 데모/발표용이면 각 1개로 축소 |
| 2 | 입장 인원 | 반경 내 **생존자 전원** 동의 | 과반 동의 / 방장 강제 |
| 3 | 개방 시간 | **보름 하루 전체** | 보름 밤만 (더 극적, 대기 길어짐) |
| 4 | 보스방 사망 | 소지품 드롭 **없음**, 관전 | 일반 사망 규칙 유지 |
| 5 | 전멸 시 | 거점 귀환, 포털 닫힘, 다음 보름 재도전 | 재료 재요구(더 가혹) |
| 6 | 클리어 후 | 엔딩 → 타이틀/새 게임 | 엔딩 후 이어서 플레이 선택 |

### 4.3 보스 아레나 안의 규칙(제안)
- **사망**: 소지품을 떨어뜨리지 않는다. 쓰러진 사람은 관전하고, **전원 쓰러지면 실패**.
- **귀환**: 클리어 또는 전멸 시 호스트가 전원을 **포털 앞 거점**으로 이동.
- **아이템 사용**: 치유 지팡이 등 전투 아이템은 그대로 사용 가능.
- **보스 처치 판정**: 보스 사망 이벤트(`Monster.Died`)를 호스트가 받아 엔딩을 발동.

## 5. 구현 방식 권고

### 5.1 씬을 나누지 않는다 (권장)
"달의 이면"을 **별도 씬으로 로드하지 않고**, 같은 씬의 **멀리 떨어진 좌표에 보스 아레나를 두고 텔레포트**한다.

- 호스트 권위 Fusion 구조에서 씬 전환은 연결/스폰 동기화가 복잡하다.
- 월드 시드, 세이브, 시계가 그대로 이어진다.
- `Player.Teleport()` 를 재사용하면 된다.
- 단점: 아레나 오브젝트가 항상 씬에 있다 → 평소에는 비활성화해 둔다.

### 5.2 필요한 신규 요소

| 요소 | 내용 | 비고 |
|:--|:--|:--|
| 월문 아이템/구조물 | `StationType.MoonGate` + 설치 프리팹 + 레시피 | 연성대와 같은 방식으로 제작 가능 |
| `MoonGateController` | 상태: `Closed → Ready → Open → InProgress → Cleared/Failed` | **호스트 확정**, `WorldClock.OnMoonPhaseChanged` 구독 |
| 네트워크 동기화 | 포털 상태/남은 시간/입장 확인 응답 | `NetworkBehaviour` 한 개 |
| HUD 안내 | "다음 보름까지 N일", 개방 중 남은 시간 | 기존 `UI_Hud_WorldState`에 추가 |
| 보스 아레나 | 학습용 아레나 모양을 재사용한 전투 공간 | 평소 비활성 |
| 엔딩 | `GameState.Ending` + 엔딩 화면 UI | 새로 필요 |
| 세이브 | 포털 설치 여부/상태/클리어 여부 | `WorldSaveAdapter`에 항목 추가 |

### 5.3 작업 순서 (보스 모델 없이 가능한 것부터)

1. 월문 아이템 + 의식 탭 + 레시피 + 설치 (연성대와 같은 방식)
2. `MoonGateController` 상태 머신 + 보름 판정 + HUD 안내
3. 집결/입장 확인/텔레포트 (멀티 포함)
4. 보스 아레나(임시 보스: 기존 트리가드로 대체) + 사망/실패/귀환 규칙
5. 엔딩 상태 + 엔딩 화면
6. 최종 보스(학습 모델) 교체

> 개발 중 테스트는 `WorldClock` 배속(최대 120배)과 보름 강제 설정 디버그 키로 한다.

## 6. 위험 요소

- **멀티 동기화**: 입장 확인/동시 이동은 호스트가 모든 클라이언트 응답을 모아야 한다. 접속이 끊긴 사람 처리가 필요하다.
- **세션 길이**: 첫 보름이 현실 1시간 36분 후라, 수집이 느리면 한 세션에 못 끝낼 수 있다. 재료 수량과 보스 스폰 빈도를 같이 조정해야 한다.
- **보스 학습 모델**: 최종 보스가 아직 없다. 임시 보스로 규칙부터 검증하고, 학습 모델은 마지막에 교체한다.
