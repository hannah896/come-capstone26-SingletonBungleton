# 테스트 요구사항 (Test Requirements)

## 1. 단위 테스트 (Unit Testing)
- **핵심 로직**: 생존 수치 감소 공식, 아이템 제작 성공 여부, 데미지 산출 로직에 대한 테스트 코드 작성.
- **상태 머신**: 플레이어 및 AI의 상태 전환(HFSM) 조건 충족 여부 확인.

## 2. 통합 및 멀티플레이어 테스트
- **P2P 연결**: 방 생성, 입장, 퇴장 시의 안정성 및 네트워크 단절 시 예외 처리 테스트.
- **동기화 검증**: 호스트와 클라이언트 간 오브젝트 위치 및 파괴 상태 일치 여부 확인.

## 3. 성능 및 부하 테스트
- **오브젝트 스트레스**: 월드 내 수천 개의 자원 노드가 배치된 상태에서 프레임 드랍 여부 확인.
- **메모리 누수**: 장시간(2시간 이상) 플레이 시 메모리 사용량의 비정상적 증가 확인.

## 4. 사용자 테스트 (QA)
- **밸런스 테스트**: 허기 감소 속도 및 자원 획득 난이도가 의도된 생존 루프에 적합한지 검토.
- **UX 테스트**: 인벤토리 및 제작 UI의 직관성 확인.
